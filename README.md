# CorreoCheck - Correo Argentino Tracking

macOS приложение для отслеживания посылок Correo Argentino

## Версия

- Текущая версия: **1.2 (15/11/2025)**

## Особенности

- 🚀 Быстрая проверка статуса посылки
- 💾 Автоматическое сохранение последнего номера отслеживания
- 🎨 Нативный macOS интерфейс на SwiftUI
- ⚡ Легковесное приложение

## Требования

- macOS 14.0+
- Swift 6.1+

## Сборка

```bash
./build_app.sh
```

После сборки приложение будет доступно как `CorreoCheck.app`

## Запуск

```bash
open CorreoCheck.app
```

## Использование

1. Введите номер отслеживания посылки
2. Нажмите "Consultar" или Enter
3. Просмотрите статус посылки

Приложение автоматически сохраняет последний использованный номер для удобства.

## Горячие клавиши

- `Enter` - Проверить статус
- `Tab` - Переключение между полями
- `ESC` - Закрыть приложение

## Технологии

- Swift 6.1
- SwiftUI
- Swift Package Manager
- Correo Argentino API
